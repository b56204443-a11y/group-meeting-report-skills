# 组会汇报skills

把近期科研记录整理成一篇《下周组会汇报准备报告》：明确**下周讲什么、已有依据是什么、会前还要准备什么**。

适用于文献梳理、实验结果整理、复现阻塞和进展零散时的组会筹备。支持中文，技能标识为 `research-progress-report`。

## 安装到 Codex

将 `skills/research-progress-report` 整个文件夹复制到自己的 Codex 技能目录：默认是 `~/.codex/skills/`；配置了 `CODEX_HOME` 时使用其下的 `skills/`。已有同名技能时先自行备份并比较，再决定是否替换。

也可从本仓库下载 ZIP，解压后复制上述文件夹。无需 API Key，不含可执行脚本，也无需安装额外依赖。实际阅读外部资料的能力取决于使用环境。

## 使用

在支持该技能的 Codex 聊天中提供课题、近期记录、导师反馈，以及可选的组会日期、汇报时长和可用时间：

```text
请用 $research-progress-report，生成下周组会汇报准备报告。
研究主题：[填写主题]
导师上次提出的问题：[填写或说明尚无反馈]
近期完成的工作：[填写真实记录]
现有文献、日志或图表：[提供与任务相关的材料]
组会日期、时长和会前可用时间：[按实际填写]
请列出拟汇报内容、已有依据、准备任务、优先级和完成标准。
```

## 报告包含什么

1. 汇报目标与当前状态。
2. 下周准备讲的内容及证据边界。
3. 会前材料与任务清单。
4. 准备顺序、完成标准和最低可汇报版本。
5. 需要导师讨论或决策的问题。
6. 会前自查。

信息不足时生成明确标注的草案。计划、初步观察和已完成成果分别表述；实验失败不自动等于方法被证伪。技能本身不自动执行实验、制作PPT或向导师发送内容。

## 隐私与资料范围

本仓库只包含通用方法、模板、技能配置及明确标注的虚构示例，不包含真实研究记录、聊天记录、原始博客截图、账号凭据或个人电脑路径。技能没有独立的联网或上传程序。

调用时提供的资料仍会交由所用 AI 工具处理；请按实际使用环境和保密要求选择材料。向公开 Issue 或 Pull Request 提交示例前，删除身份信息、未公开数据、凭据和个人绝对路径。
